# AppRoomBackend
## Hakkında

ASP.NET Core Web API ile geliştirilen, oyun backend işlemlerini yöneten RESTful API projesidir.
## Kullanılan Teknolojiler
- **C#** — Backend geliştirme
- **ASP.NET Core Web API** — RESTful API
- **Entity Framework Core** — ORM ve veri erişimi
- **SQL Server** — Veritabanı
- **JWT** — Kimlik doğrulama ve yetkilendirme
- **BCrypt** — Şifre hashleme
- **Swagger** — API test ve dokümantasyon
- **Git / GitHub** — Versiyon kontrolü

## Özellikler

- Karakter ve eşya CRUD işlemleri
- Kategori yönetimi
- Kullanıcı kayıt ve giriş sistemi
- JWT tabanlı authentication
- User / Admin rol bazlı authorization
- Veri doğrulama ve hata yönetimi.
